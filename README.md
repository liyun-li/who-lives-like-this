# Who Lives Like This?

A floor-plan guessing game: real HABS measured drawings, names redacted. Read the room labels, pick who lived there (3 options).

- Play: https://liyun-li.github.io/who-lives-like-this/
- 30 rounds; 10 per game, unseen rounds first (localStorage key `wllt_seen`).
- Pinch zoom up to 5x, double-tap zoom, tap to open full-screen.
- Drawings: Historic American Buildings Survey, National Park Service — public domain. See [credits](credits.html).
